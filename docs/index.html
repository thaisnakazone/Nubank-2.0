04 · Reclamações · Banco Central

Quais reclamações viram risco de conduta?

O Banco Central classifica cada reclamação por tipo de irregularidade e marca como procedente quando confirma que o banco descumpriu uma norma — um sinal direto de risco operacional e de conduta.

Dados do Banco Central ainda não coletados. Eles são coletados automaticamente pelo workflow Reclamações BCB no GitHub Actions.

Grupos de reclamações descobertos por machine learning

Um algoritmo de agrupamento (K-Means) leu os títulos das 122 reclamações e juntou as que usam palavras parecidas, sem receber categorias prontas. Os nomes resumem o tema de cada grupo.
